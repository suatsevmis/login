# **POKEMON KARTLARI PROJESİ 

## **ÖZELLİKLERİ 

- Bu proje,  PokeAPI servisinden yararlanarak ilk nesil 151 Pokémon'u kartının bulunduğu bir web dosyasıdır.


## KULLANILAN TEKNOJİLER 
-Başta HTML ile sitenin ön yüzü yapılmıştır.
-İkinci olarak CSS3 ile stillendirilmiştir.
-Üçüncü olarak JAVASCRİPT(ES6+) ile de Async/Await ve DOM dinamik algoritmalar kulanılmıştır.


## KULLANILAN API SERVİSLERİ
-Projedeki tüm veriler ve görseller açık kaynaklı PokeApı sitesinden çekilmiştir.

** Pokémon Detayları (İsim, Tip, İstatistikler): https://pokeapi.co/api/v2/pokemon/{id}
**Pokémon Görselleri (Sprites): https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/{id}.png

## PROJE YAPISI 

----  index.HTML      # Uygulamanın ana HTML dosyası.
----  style.css       # Stil ve tasarım dosyası. 
----  script.js       # API ve arama mantığı.
